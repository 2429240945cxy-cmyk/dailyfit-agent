# Data Sources

- Open Food Facts API v2: live product search and nutrition labels.
- USDA FoodData Central: live search when `USDA_API_KEY` is configured.
- HPB/FOCOS cache: manual cached local dish rows, never presented as live API.
- free-exercise-db: public-domain exercise JSON from `yuhonas/free-exercise-db`.
- Local fallback: explicit demo and last-resort fallback only.
